# Wafer-GUARD — Repaired Wafer Anomaly Detector

> **Five-line evaluator summary**
> - Three original defects: preprocessing/SMOTE leakage, `[B,1,F]` reconstruction broadcasting, and mishandled PS-L sentinel/categorical codes.
> - Reproduced contaminated baseline: F1 `0.9915`; repaired chronological holdout: F1 `0.1311` (not directly comparable as a clean model-only ablation).
> - Final holdout: precision `0.0723`, recall `0.7059`, AP `0.0841`; 166/314 rows flagged.
> - Decision: **NO-GO** — no stable useful ranking signal demonstrated; do not claim production readiness.
> - Reproduce: install `requirements.txt`, run `python -m pytest -q`, then execute every cell in `wafer_guard_fixed.ipynb`.


## Required challenge deliverables
- `wafer_guard_fixed.ipynb` — repaired PyTorch notebook.

## Grader criteria: where to verify each requirement

| Criterion | Notebook location | Concrete verification |
|---|---|---|
| Causality-safe preprocessing | Sections 1–2 (cells 1–7) | Chronological 60/20/20 split; imputer and scaler fit on the first 60% only; validation/test remain at natural prevalence; no SMOTE in the repaired path. `audit_checks.py` checks split and prevalence assumptions. |
| Tensor shapes and gradients | Sections 1 and 3 (cells 2–3, 8–10, 14–15) | Prints the original `[64,1,590] - [64,590] -> [64,64,590]` broadcast; repaired assertions require reconstruction/input shapes to match and logits/labels to both be `[B]`. |

## Requirements and setup
The recorded full execution environment was Python `3.13.5`, PyTorch `2.10.0+cpu`, scikit-learn `1.8.0`, NumPy `2.3.5`, pandas `2.2.3`, and Matplotlib `3.10.8`. Dependencies in `requirements.txt` are version-ranged rather than fully pinned; for strict reproduction, record the resolved `pip freeze` from the submission environment. python -m pip install --upgrade pip


## Measured performance and limitations

The saved outputs are recorded results from the packaged run; rerun the notebook in a clean environment before submission to verify them independently. The recorded final test set contains 314 rows and 17 defects (5.41% prevalence). The saved metrics report F1 `0.1311`, precision `0.0723`, recall `0.7059`, ROC-AUC `0.6243`, and average precision `0.0841`. An iid row-bootstrap gives descriptive 95% intervals: F1 `[0.068, 0.199]`, precision `[0.036, 0.113]`, recall `[0.500, 0.905]`, ROC-AUC `[0.490, 0.751]`, and average precision `[0.047, 0.158]`; temporal dependence is not accounted for. The notebook also reports top-5% and top-10% alert-budget metrics. The fixed-model diagnostics report permutation tests separately for both the supervised probability and the auxiliary reconstruction-error score. For each score, AP uses an upper-tail permutation test and AUC uses a two-sided test against 0.5, each with 5,000 row-wise label permutations; see `artifacts/fixed_model_diagnostics.json` for score-specific values. Row-wise permutations ignore temporal dependence and are descriptive only. The test period covers only October 2008, so its monthly chart cannot show a month-to-month trend. The model is **NO-GO for production**; useful ranking signal is not demonstrated. A supporting pooled out-of-time evaluation over 470 rows has AP `0.0407` against pooled prevalence `0.0426`; see `artifacts/pooled_oot_metrics.json`. Do not claim F1 >= 0.90 or production readiness.
